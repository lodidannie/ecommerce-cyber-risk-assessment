# 08 - Executive Summary

JEDEM depends on customer/payment data, application/backend services, operational systems, intellectual property and customer trust.

The source rates application exploitation and denial of service as High, data breach as Medium, and insider threat plus misuse/non-compliance as Low.

Estimated security investment:
- Data protection: $60K / 3 months
- Application security: $40K / 2 months
- Governance & compliance: $15K / 1 month

Management would still need to decide which risks exceed tolerance, which treatments are funded, who owns each risk, and what residual risk can be accepted.
