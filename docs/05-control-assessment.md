# 05 - Control Assessment

## Preventive
Encryption, Zero Trust, MFA, access controls, least privilege/RBAC, WAF, input sanitization, SSL/TLS, CSP, awareness, background checks, separation of duties, CDN, rate limiting.

## Detective
DLP, IDS/IPS, network traffic analysis, SIEM, web-server monitoring, API alerts, auditing, activity monitoring, anomaly detection, audit trails.

## Corrective
Backups, incident response, versioning, notification, digital forensics, emergency patching, root-cause analysis, policy review, offboarding and remediation training.

## Limitation
The source identifies control coverage but does not provide evidence of design or operating effectiveness. Therefore this project does not claim the controls were tested.
